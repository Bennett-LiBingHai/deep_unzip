# 第一章 文档说明

## 1.1 编写目的

本文档是 DeepUnzip 文件解压软件（以下简称「本软件」或「本应用」）的用户手册，
用于说明本软件的运行环境、界面结构、各项功能的操作步骤与注意事项。

本文档的读者是使用本软件的个人用户与技术支持人员。阅读本文档不需要压缩算法
或移动开发方面的背景知识；涉及格式、分卷、加密等概念的地方，都在正文里就地
解释过。

本文档同时作为本软件著作权登记的文档鉴别材料提交。

## 1.2 文档结构

全文分二十章。前八章讲日常操作：装、看、选、解、找。中间七章讲各项进阶能力与
相应的设置项。最后五章是格式清单、隐私说明、常见问题与故障排除。

每一章的小节独立成篇，可以跳着看。查找具体某个开关的含义，直接翻到「设置」一章
即可；查找某种格式是否支持，直接翻到「支持的格式」一章。

## 1.3 术语约定

文中出现的几个词，在此处一次性说清，后文不再重复解释。

| 术语 | 含义 |
| 压缩包 | 一个可被本软件解开的归档文件，如 a.zip、b.7z、c.tar.gz |
| 条目 | 压缩包内部的单个文件或空目录 |
| 分卷 | 一个被切成多个文件的压缩包，如 x.zip.001、x.zip.002 |
| 首卷 | 分卷里排在最前面的那一片，解开时从它开始 |
| 嵌套包 | 一个压缩包里装着的另一个压缩包 |
| 递归 | 解开嵌套包，以及进入子目录继续查找 |
| 扫描 | 在选定范围内查找压缩包并判断其格式，不写入任何数据 |
| 解压 | 把压缩包里的条目写到磁盘上 |
| 输出目录 | 解压结果落在的目录 |

文中用「点击」指轻触屏幕，用「长按」指按住不放。「选择目标文件 / 文件夹」、
「开始解压」这类带引号的词，都与界面上的按钮或文字一一对应。

## 1.4 版本信息

本文档对应的软件版本为 V1.0.0。软件版本号可在「设置」页最下方「关于 DeepUnzip」
一行里查到，该页同时给出隐私说明与第三方组件的许可全文。

若界面上的文字与本文档不一致，以界面为准 —— 那说明您手上的是更新的版本。

# 第二章 软件概述

## 2.1 软件简介

DeepUnzip 是一款运行在 Android 系统上的本地解压工具。它面向的使用场景很具体：
手机上攒了一堆压缩包，格式杂、有的带密码、有的被切成好几片、有的后缀还被改过，
需要一个工具一次性处理掉，并且处理过程要看得见。

本软件不联网。发布版本不声明网络权限，不包含任何统计、崩溃上报或广告组件，
也不会把文件名、文件内容或路径发送到任何地方。全部识别与解压过程都在本机完成。

## 2.2 设计目标

一、**认得出**。不靠后缀名判断格式，而是读文件开头若干字节的特征值（魔术字节）。
后缀被改成 .pdf 的 ZIP 包，照样能认出来并正确解开；粘贴在图片等文件后面的压缩包，
也能找出来。

二、**解得开**。内置完整的解码核心，覆盖常见压缩包、压缩流、软件包与磁盘映像。
不调用系统外部命令，也不依赖第三方解压程序是否安装。

三、**讲得清**。解压中遇到任何需要判断的情况都如实呈现：解不开时说明原因，
分不清是密码错还是文件坏的时候，就明说分不清，不替用户下结论。

四、**不失控**。对压缩炸弹设有多道闸门，并且在动手写盘之前先量一次目标卷的剩余
空间。宁可不解，也不把设备塞满。

五、**可追溯**。每一次扫描与每一次解压都留下一条日志，含结果、耗时与标记。

## 2.3 主要功能

- 递归解压：选定一个文件夹，自动向下遍历，把找到的压缩包全部解开，解开后
  又发现的嵌套包继续解，深度上限可设。
- 单文件解压：也可以只选中一个压缩包，只解它，同目录里没被选中的一概不动。
- 格式识别：按文件头识别三十二种格式，后缀与实际格式不符时给出提示。
- 分卷支持：支持四种分卷家族，自动判断首卷、校验分片连续性。
- 密码库：保存常用密码，遇到加密压缩包时自动逐个尝试；试不出来时询问用户，
  也可以手动输入。
- 输出位置可选：默认解到每个压缩包旁边、与源目录结构对称；也可以指定一个根
  目录，按源目录的相对结构镜像写进去。
- 进度可见：实时显示百分比、当前文件、已完成数量、速度、递归层数与预计剩余时间。
- 长任务保活：解压期间开启前台服务并显示通知栏进度，切到后台或锁屏不会被系统
  回收。
- 日志：每个压缩包一条记录，可按结果筛选，保留条数可设。
- 自建文件浏览器：不依赖系统文件选择器，选中大文件时不会预先复制一份到应用缓存。

## 2.4 功能边界与已知限制

以下几条是当前版本明确不做或做不到的事，在遇到时不会报错，但不应当作缺陷。

- 本软件**只解压，不压缩**。它不会创建压缩包，也没有压缩格式转换功能。
- 规则包与自定义解压方式**不支持从网络下载**，只能从本机文件导入。这是为了保证
  本软件始终保持「单机应用」的性质。
- 分卷压缩包在**只选中单个文件**的模式下有固有限制：只能点中其中一片。此时界面
  会提示改用「选择文件夹」。
- 「输出根目录」只在本次运行期间记住，不写入磁盘。重启应用后，上一次的输出目录
  不会被自动识别，重新扫描时可能把上一次解出来的内容也扫进来。
- 解压中途可以停止。按下停止后当前这个压缩包随即中断，通常不到一秒；写到一半的
  那个文件会被删除，这次解压新建的空目录也会被收掉，之前已完整解出的文件不受影响。
- 被加固（加壳）的安装包可能会破坏本地库的加载。本软件建议不加壳，或只开启
  「仅反调试」模式。

# 第三章 运行环境与安装

## 3.1 硬件要求

本软件对硬件的要求不高，与 Android 系统本身的要求一致。

| 项目 | 要求 |
| 处理器 | ARM64、ARMv7 或 x86_64 架构 |
| 内存 | 建议 2 GB 及以上 |
| 存储 | 安装约占 30 MB；解压另需空间，见下 |
| 屏幕 | 支持任意分辨率，界面按竖屏设计 |

解压所需的存储空间取决于压缩包解开后的总量，不是压缩包本身的大小。本软件在
开始解压前会读取压缩包声明的解压后总量，并与目标卷的剩余空间比对；空间不足时
直接放弃并告知用户，不会写到磁盘将满才失败。

## 3.2 软件环境

| 项目 | 要求 |
| 最低系统版本 | Android 7.0（API 24） |
| 目标系统版本 | Android 16（API 36） |
| 应用包名 | com.bennett.deep_unzip |
| 支持的处理器架构 | arm64-v8a、armeabi-v7a、x86_64 |

存储权限在不同系统版本上走三条不同的路，本软件都已经适配，用户不需要关心：

| Android 版本 | 使用的存储权限 |
| 7.0 至 9 | 读写外部存储权限 |
| 10 | 读写外部存储权限，另加传统外部存储模式 |
| 11 及以上 | 所有文件访问权限 |

Android 13 及以上还需要通知权限，用于在解压期间显示进度通知。Android 14 及以上
另需声明前台服务类型。这两项都由本软件在清单中声明，安装时无需用户操作。

## 3.3 安装步骤

一、从应用商店或软件发行页面下载安装包文件，扩展名为 .apk。

二、在设备的文件管理器中找到该文件并点击。若系统提示「不允许安装未知来源的
应用」，按提示进入系统设置，为本文件管理器开启「安装未知应用」的权限，然后返回
继续。

三、在安装确认页上核对应用名称与所需权限，点击「安装」。

四、等待安装完成，点击「打开」即可启动；也可以点「完成」，之后从桌面图标启动。

安装包使用发布证书签名。若设备上已经装过同一应用的测试版本，可能出现「应用未
安装」的提示，此时需要先卸载旧版本再安装。

## 3.4 首次启动与权限授予

首次启动时，本软件只显示主界面，不会主动弹出任何权限申请 —— 这是有意为之：还
没有用到需要权限的功能时，就不应该申请。

当您第一次点击首页那张「选择目标文件 / 文件夹」的卡片时，本软件会先说明用途，
然后发起存储权限申请。在 Android 11 及以上系统中，会跳转到系统的「所有文件
访问」授权页，需要在该页中手动打开开关。

> 关于「所有文件访问权限」：本软件的核心功能是跨目录递归查找压缩包并把结果写回
> 磁盘，这属于「文件管理器类应用」的典型用途，也是该权限允许的用途之一。本软件
> 不会读取与解压无关的文件。

如果您拒绝了授权，本软件不会退出，也不会循环弹窗。首页会给出提示，您可以随时
再次点击该卡片重新发起申请。授权页的入口也在「设置」页中保留。

## 3.5 升级与卸载

**升级**：直接安装新版本的安装包即可覆盖。设置项、密码库与日志都会保留。升级
不会触碰已经解压出来的文件。

**卸载**：在系统的「设置 → 应用 → DeepUnzip」中选择卸载，或长按桌面图标后选择
卸载。卸载会一并删除本软件保存的设置、密码库与日志。已经解压出来的文件属于用户
数据，不在应用私有目录内，卸载时不会被删除。

> 需要提醒的是：密码库保存在系统提供的加密存储中，随应用一起卸载。卸载前请确认
> 没有还需要用到的密码。密码本身记在别处是更稳妥的做法。

## 3.6 安装包的构成

安装包内包含以下内容，了解这一点在排查安装问题时有用：

| 内容 | 说明 |
| 应用代码 | Dart 与 Flutter 编译产物 |
| 解压核心 | 一个本地库，实现全部格式的解码 |
| 界面资源 | 图标、字体与主题定义 |
| 许可声明 | 第三方组件的许可文本，可在应用内查阅 |

解压核心是本地库而不是脚本，这是本软件能把几十种格式都做进一个安装包里的原因，
也是它在加固之后可能启动异常的原因，见 21.7 节。

安装包按处理器架构分别提供。设备只需要自己那一份架构，商店在分发时会自动挑选。
本软件支持 `arm64-v8a`（当前绝大多数设备）、`armeabi-v7a`（较早的 32 位设备）
与 `x86_64`（模拟器）。若手动安装，请选择与设备匹配的那一份。

## 3.7 各类文件存在哪里

本软件涉及三类数据，位置与生命周期各不相同：

| 数据 | 位置 | 卸载时 |
| 设置、日志、密码库 | 应用私有目录 | 一并删除 |
| 解压结果 | 用户指定的位置，或压缩包旁边 | 保留 |
| 压缩包原位 | 用户自己的文件 | 保留（开启自动删除时为删除） |

应用私有目录由系统管理，其他应用无法读取。解压结果落在外部存储，是本软件的产物
也是您的数据，卸载不会删除它。

## 3.8 权限被拒绝之后

拒绝授权不会让软件变得不可用，只会让「跨目录查找压缩包」这件事做不了。重新授权
有两条路：

一、再次点击首页的「选择目标文件 / 文件夹」。本软件会重新发起申请。为了避免
打扰，短时间内不会反复弹出，稍等片刻再试即可。

二、进入系统的「设置 → 应用 → DeepUnzip → 权限」，手动打开「所有文件访问」。

授予之后不需要重启应用，当场生效。

> 本软件不会因为权限被拒绝而退出、也不会循环弹窗。这与部分应用的做法不同，是
> 有意守住的底线：权限是用户的权利，不是使用软件的门票。
