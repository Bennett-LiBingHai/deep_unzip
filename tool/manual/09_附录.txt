# 附录 A 界面文字速查

本附录按界面出现的位置，列出全部对用户可见的固定文字。用途是核对：如果在应用
里看到某句话而这里没有，或者在帮助文档里引用了一句话而应用里找不到，那就是有
一处需要同步。

## A.1 首页

| 界面文字 | 位置 | 含义 |
| 选择目标文件 / 文件夹 | 首页入口卡片 | 打开自带的文件浏览器 |
| 已选 | 首页目标卡片 | 显示当前选中的目录或文件 |
| 更换 | 首页目标卡片 | 重新选择；解压进行中不可点 |
| 正在递归扫描 | 首页扫描面板 | 扫描进行中 |
| 已发现 N 个 | 首页扫描面板 | 扫描进行中的实时计数 |
| 取消扫描 | 首页扫描面板 | 中止本次扫描 |
| 扫描结果 | 首页结果卡片标题 | 本批发现的压缩包列表 |
| N 个压缩包 | 首页结果卡片 | 列表长度 |
| 总文件 N · 需密码 X · 特殊格式 Y | 首页结果卡片 | 三个汇总计数 |

| 正在扫描… | 首页主按钮 | 扫描中，不可点 |
| 停止解压 | 首页主按钮 | 解压进行中 |

# 附录 B 关键参数一览

## B.1 可调参数

| 项目 | 出厂默认 | 可调范围 | 设置位置 |
| 最大递归深度 | 20 | 0 至 64 | 递归与目录 |
| 自定义输出目录 | 关闭 | 开 / 关 | 递归与目录 |
| 伪后缀时暂停 | 开启 | 开 / 关 | 智能识别 |
| 无法解密时弹窗 | 开启 | 开 / 关 | 智能识别 |
| 手输密码存入密码库 | 开启 | 开 / 关 | 智能识别 |
| 错误时暂停 | 开启 | 开 / 关 | 错误处理 |
| 解压上限档位 | 标准 | 四档循环 | 炸弹防护 |
| 日志保留条数 | 300 | 1 至 5000 | 日志 |

## B.2 限额档位

| 档位 | 条目数 | 单文件 | 总量 | 压缩比 |
| 宽松 | 1,000,000 | 64 GB | 512 GB | 5000 : 1 |
| 标准 | 200,000 | 8 GB | 64 GB | 1000 : 1 |
| 严格 | 20,000 | 1 GB | 8 GB | 200 : 1 |

「自定义」不是一个固定档位，它是四档循环里的第四档；切进去时会把上一个档位的
数值原样带过来当起点。

## B.3 不可调的常量

| 项目 | 值 | 说明 |
| 压缩比地板 | 1 GB | 解压总量不到 1 GB 时不看比值 |
| 空间检查余量 | 64 MB | 判空间时给目标卷留的底 |
| 深度硬顶 | 64 | 用户能填的上限 |
| 后缀剥离 | 一路剥到底 | c.tar.gz 解成 c 而不是 c.tar |

# 附录 C 术语表

本附录解释手册里出现的术语。凡是在正文里第一次出现时没有解释的，都能在这里
查到。

| 术语 | 含义 |
| 压缩包 | 一个归档文件，内含若干条目；本手册中也叫「包」 |
| 条目 | 压缩包内部的一个文件或一个目录 |
| 归档 | 与「压缩包」同义，强调它是一份被组织起来的集合 |
| 容器格式 | 内部结构是归档、但用途是文档或程序包的文件，如 apk、docx |
| 魔术字节 | 文件开头的若干固定字节，用来判断格式 |
| 文件头 | 文件开头的若干字节；手册里也指读出来的那一段特征值 |
| 嗅探 | 读文件头判断格式的过程 |
| 伪后缀 | 文件名的后缀与内容实际的格式不符 |
| 级联探测 | 认不出格式时按固定顺序逐个格式试开，只列条目不写数据 |
| 分卷 | 一个大文件被切成若干片存放，使用时需要全部拼起来 |
| 首卷 | 分卷包里排在最前面的那一片 |
| 裸字节切分 | 按固定字节数切开、文件名后面追加数字后缀的分卷方式 |
| 嵌套包 | 从一个压缩包里解出来的压缩包 |
| 递归深度 | 往下一层走一步所消耗的预算；进子目录与解嵌套同等计入 |
| 目录对称输出 | 默认的输出方式，每个包解到它自己旁边，结果树与源树同形 |
| 镜像输出 | 自定义输出目录下的方式，按源目录的相对结构写进输出根 |
| 输出根 | 自定义输出目录模式下由用户选定的那个根目录 |
| 炸弹 | 声明体积远大于实际体积、解开后可能撑爆磁盘的压缩包 |
| 炸弹防护 | 按条目数、单文件、总量、压缩比四项阈值拦截超限的包 |
| 限额档位 | 一组预设的四项阈值；宽松、标准、严格三档，外加自定义 |
| 密码库 | 保存候选密码、解压时自动逐个尝试的本地仓库 |
| 候选密码 | 密码库里的密码；不与具体某个包绑定 |
| 命中 | 某个候选密码成功解开了一个包 |
| 校验字 | 加密格式里用来判断密码对错的一段固定数据 |
| 密码未匹配 | 有校验字的格式给出的确定结论：密码不对 |
| 密码或损坏 | 无校验字的格式下，分不清是密码错还是数据坏 |
| 自引用 | 一个压缩包里装着它自己，继续解会无限循环 |
| 所有文件访问 | Android 的 MANAGE_EXTERNAL_STORAGE 权限 |
| 前台服务 | Android 的长任务保活机制，运行时通知栏有常驻通知 |
| 输出目录 | 某一批解压结果落下的位置 |

# 附录 D 日志标记与状态对照

日志页每条记录由**一个状态**加**若干个标记**组成。两者是分开的：状态回答
「这件事最后怎么样了」，标记回答「过程中发生了什么」。

## D.1 四种状态

| 状态 | 颜色 | 含义 |
| 成功 | 绿色 | 这个包完整解开了 |
| 失败 | 红色 | 没有解开，且原因是错误 |
| 跳过 | 橙色 | 没有解开，但这是按规则主动放弃的 |
| 部分 | 橙色 | 解出了一部分，有个别条目没解出来 |

「跳过」与「失败」刻意分开：用户看到一排红字会以为程序坏了，而跳过其实都是
按规则拦下来的正常行为，例如自引用、超过深度上限、用户在伪后缀弹窗上选了取消。

## D.2 标记全表

| 标记 | 出现在 | 含义 |
| 分片 ×N | 成功 | 这是一个 N 片的分卷包 |
| 嵌套 | 任意 | 这个包是从别的包里解出来的 |
| 加密 | 任意 | 这个包有密码 |
| 密码库 | 成功 | 用密码库里的密码解开的 |
| 手输密码 | 成功 | 用手动输入的密码解开的 |
| 伪后缀 | 任意 | 后缀与实际格式不符 |
| N 项 | 成功 | 解出了 N 个条目 |
| 炸弹防护 | 失败 | 规模超过设定的上限，主动放弃 |
| 空间不足 | 失败 | 目标卷剩余空间不够 |
| 密码未匹配 | 失败 | 确定是密码不对 |
| 密码或损坏 | 失败 | 分不清是密码错还是数据坏 |
| 解压失败 | 失败 | 压缩包损坏或其它错误 |
| N 个压缩包 | 成功 | 扫描记录发现的数量 |
| 忽略 N 个容器 | 成功 | 扫描时跳过的容器格式文件数 |
| N 个不可读 | 成功 | 扫描时读不了的文件数 |

## D.3 扫描记录

扫描本身也是一条记录，与解压记录并列，标题写成「目录名（扫描）」。它的大小是
本批各包之和，标记里给出发现的数量，以及被跳过的容器数与不可读的文件数。

扫描记录与解压记录分开，是为了让「扫了一次但没解」这件事在日志里留下痕迹 ——
否则用户会以为这次操作什么都没发生。

## D.4 日志里没有的东西

日志里**不记录完整路径**，只记录压缩包的文件名；也**不记录密码**，只记录密码的
来源。两条都是有意为之：日志文件是明文的，完整路径会暴露用户的目录结构与习惯，
密码则等于绕过了加密存储那道防线。见 15.5 节。

## D.5 日志能回答什么、不能回答什么

日志是一份**结果记录**，不是审计记录。它的边界值得说清楚，免得在需要的时候
指望它。

能回答的问题：

- 这个包解开没有？—— 看状态。
- 用了哪个密码来源？—— 看「密码库」或「手输密码」标记。
- 解出了多少东西？—— 看「N 项」标记。
- 花了多久？—— 看耗时。
- 失败了，是哪一类？—— 看标记与说明。

不能回答的问题：

- 这个包原来放在哪个完整路径下？—— 只记文件名，不记路径。
- 当时用的是什么密码？—— 只记来源，不记密码本身。
- 当时那一批用的是哪一组限额？—— 不记。限额是当时的设置，不是结果的一部分。
- 当时磁盘还剩多少？—— 不记。空间不足时只记结论。
- 用户当时点的是「跳过」还是「停止」？—— 只记这个包的结果，不记按键。

最后一条尤其容易误会：日志里的「跳过」状态说的是**这个包被放弃了**，至于是软件
按规则放弃的还是用户按了按钮放弃的，要结合标记来判断 —— 有「自引用」「超过深度
上限」这类标记的是前者，没有标记而状态是跳过的，多半是后者。

想知道某一批解压时的完整参数，正确的做法是在点「开始解压」之前看一眼确认卡片，
而不是事后翻日志。日志记的是「发生了什么」，不是「当时是怎么设的」。

一句话总结这份手册的使用方式：装好之后，选一个目录，扫一遍，看一眼结果卡片上
的三个计数，然后按下主按钮。剩下的部分 —— 密码、分卷、伪后缀、限额、空间 ——
都可以在遇到的时候再回来查对应的章节。

文档结束。
